# 监控探测平台（Monitoring Platform）

> 状态: stable
> 最后更新: 2026-11-25
> 反推来源: beacon 上报 handler、告警任务与监控查询实现，以及 beacon-web 监控图表组件的既有事实

## 设计意图

约束 Server-Agent 监控探测平台的采集、控制、告警、Agent 选择、数据新鲜度和操作可观测性，保证用户看到的主机与容器运行状态可信。

本文件描述长期有效的领域约束：只写必须满足什么、允许什么、禁止什么，以及如何验证；不写实现步骤、临时文件路径、局部命名方案、可替换技术选型或伪代码。若路径本身是稳定协议表面，必须说明其契约身份与验收方式。

## 约束空间

### 不变量（始终成立的断言）

| 编号 | 不变量 | 验收方式 |
|------|--------|----------|
| I001 | 每个需要访问 Agent 的请求必须能解析出唯一目标 Agent；无法解析时必须使用明确的默认 Agent 或返回可见错误。 | 建议用 API/RPC 集成测试覆盖显式 Agent、默认 Agent 和未知 Agent。 |
| I002 | 主机、容器和告警数据必须携带可判断新鲜度的时间或采集批次信息；过期数据禁止展示为实时状态。 | 建议用数据查询测试覆盖新鲜、过期和空数据。 |
| I003 | 容器运行时的启动、停止、重启、删除、镜像拉取和网络变更必须只作用于被选中的目标 Agent。 | 建议用多 Agent 目标场景验证操作目标与审计记录一致。 |
| I004 | 告警状态必须由可观测指标、阈值配置和恢复条件共同决定，禁止只由前端展示状态推导。 | 建议用告警规则单测覆盖触发、保持、恢复和缺失数据。 |
| I005 | Agent 上报的同一监控批次必须作为一个一致性单元被接受或拒绝；禁止留下同一批次的部分写入状态。 | 建议用上报存储测试覆盖成功批次、缺失 Agent 和写入失败回滚。 |
| I006 | 用户可选 Agent 列表必须来自当前 Server 进程可观测的 Agent 生命周期状态；进程重启后禁止把上一进程残留的 `online` 标记返回为当前在线，禁止前端用固定默认值替代真实可用节点。 | 用 Agent 列表 API 与连接/断开生命周期测试覆盖重启残留状态、在线、离线和空列表。 |
| I007 | 监控页面的时间密度必须表示以当前刷新时刻为终点的最近时间窗口；查询结果与图表横轴必须共同受开始和结束边界约束。 | 建议用 Repository 和组件测试覆盖 5/10/30 分钟、空窗口及越界样本。 |
| I008 | 告警通道凭据属于敏感配置；查询接口、日志和错误不得返回完整 Webhook access token、签名密钥或机器人 key，只能返回掩码与是否已配置状态。 | 用钉钉/飞书/企业微信配置的 service/client 测试覆盖查询掩码、上游错误和超时错误。 |
| I009 | Server 启动时内置角色的资源关联与 Casbin 策略必须和当前具名路由集合一致；管理员拥有管理员专属告警配置权限，普通用户不得因 GET 路由默认授权而获得该权限。 | 用已有角色升级回归测试覆盖重复初始化、管理员访问、普通用户拒绝和陈旧策略清理。 |
| I010 | 活动告警阈值配置中 `cpu`、`memory`、`disk` 必须各有且仅有一条规范记录；Server 重复启动不得覆盖用户已保存的阈值，旧 `mem` 记录必须无损迁移为 `memory`。 | 用 Prepare 数据迁移测试覆盖缺失记录、旧别名、重复记录、用户覆盖值和重复初始化。 |
| I011 | 告警消息标题必须由 Server 单例持久化并在重启后保留；邮件 Subject 与钉钉/飞书/企业微信文本首行及对应测试消息必须读取同一标题，审计正文不得因展示标题而改变。 | 用 Prepare、Repository、通知任务和发送器测试覆盖默认值、更新、重启保留及多通道一致性。 |
| I012 | CPU、内存和磁盘使用率统一使用 `0–100` 百分数；Server 禁止对 Collia 上报值再次乘以 100。 | 用 65.2% 内存对 80% 阈值、55% 磁盘对 85% 阈值的回归测试验证不误报。 |
| I013 | “持续 N 分钟”必须由 Server 接收时间形成完整连续窗口，窗口首尾足够新、样本间无超限间断且所有样本严格高于阈值才进入告警；单点、缺失、陈旧或间断数据属于未知状态。 | 用单点高值、完整高值、夹杂正常值、间断和陈旧样本测试覆盖。 |
| I014 | 只有已触发告警在获得完整正常证据后才能恢复；未知数据不得触发或恢复。恢复审计和通知只发送一次，并清除去重状态，使后续再次越界可立即触发。 | 用触发、重复检查、恢复、重复恢复和再次越界测试验证。 |
| I015 | Agent 监控上报必须使用 Server 已配置的非空共享 Token，并只通过专用请求头传递；Server Token 未配置时必须拒绝服务，禁止以关闭认证方式继续接收。 | 用未配置 Token、缺失/错误请求头、query token 和合法请求头的 handler 测试验证。 |
| I016 | SMTP 密码与钉钉/飞书/企业微信机器人凭据（Webhook、签名密钥）必须使用部署期持久密钥加密存储；查询、日志、错误和版本控制不得暴露明文或数据加密密钥。 | 用明文迁移、加解密、掩码查询和部署变量检查验证。 |
| I017 | 产品不得暴露主机 DNS、系统时间、时区、重启或关机设置能力；Web 路由、HTTP API 与反向控制 RPC 均不得注册这些操作。 | 用前端路由、HTTP 路由和 Agent RPC 调度器测试确认相关入口与方法不存在。 |
| I018 | 容器监控必须在容器数量较多或名称较长时保持绘图区不被图例遮挡；全部容器序列仍须可见，且被截断的名称必须可查看完整值。 | 用高基数容器组件测试覆盖图例滚动、名称提示、内部图例关闭和全部序列保留。 |
| I019 | 监控上报的共享 Token 校验必须使用恒定时间比较原语，禁止可用可测量时序差异区分的逐字节比较。 | 代码审查确认使用恒定时间比较；对同前缀不同长度的候选 Token 计时，无可稳定复现的差异。 |
| I020 | Agent 上报必须拒绝非 HTTPS 目标地址，并拒绝包含用户信息的地址；禁止以明文传输或 URL 内嵌凭据的方式发送上报 Token。 | 以 `http://` 与带 userinfo 的地址构造上报客户端，断言发送被拒绝且不产生网络请求。 |
| I021 | HTTP 兼容回落上报的 HTTPS 客户端必须使用系统信任根校验 Web 端点证书，禁止复用控制通道信任配置或跳过证书校验；私有 CA 签发的 Web 证书只有在其根证书已导入系统信任库后才可被接受。 | 用 TLS 配置与客户端测试覆盖系统信任库、拒绝不受信自签证书；在受信公有 CA 与已导入系统信任库的私有 CA 场景分别验证上报成功。 |
| I022 | 存活探针不得依赖数据库或任何外部依赖，必须只反映进程自身存活；就绪探针必须反映数据库连通性。就绪探针不承诺 Agent 隧道可达性，禁止把在线 Agent 数量作为就绪条件。 | 数据库不可用时存活探针返回 200、就绪探针返回 503；数据库恢复后就绪探针恢复 200；无任何 Agent 连接时就绪探针仍返回 200。 |
| I023 | 登录类敏感端点必须按来源 IP 严格限流；Agent 上报必须按 Agent 身份限流；其余 API 必须有全局兜底限流，且兜底限流不得对已由严格限流接管的端点重复计数。 | 超限返回 429；登录端点在同一窗口内只被计入严格限流，不叠加全局计数。 |
| I024 | 实时通道的读写必须设置超时兜底，流式控制调用必须有最长生命周期上限，反向隧道连接必须有超龄与空闲回收；半开连接不得导致服务端 goroutine、缓冲或连接条目永久占用。 | 构造半开 TCP 与 Agent 挂起场景，断言读/写超时触发、流式调用被取消并释放缓冲、超龄连接被回收。 |
| I025 | HTTP 请求体必须设有大小上限，连接必须启用读、写与空闲超时；禁止以无上限的请求体或无限等待的连接占用服务端内存。 | 发送超上限请求体断言被拒绝；慢速请求在超时后被关闭。 |
| I026 | 审计记录必须同时携带操作对象与目标 Agent 标识；仅记录动作名不足以定位“谁对哪个资源做成了什么”。非 Agent 作用域的操作允许目标 Agent 为空。 | 对容器执行启停与删除后查询审计，断言记录包含被操作容器标识与 Agent 标识；登录等非 Agent 操作允许 Agent 为空。 |
| I027 | 审计日志必须按部署配置的保留期自动清理；禁止因未纳入清理任务而无上限增长。 | 写入超过保留期的审计记录后执行清理任务，断言被移除；保留期内的记录保留。 |
| I028 | 上报 TLS 配置不得读取或注入控制通道客户端证书、控制 CA 或控制通道 ServerName；本机 Unix Socket 控制面与 Web 上报信任判定必须解耦，禁止因控制面无证书而降低 Web 证书校验强度。 | 代码审查确认上报 TLS 配置不引用控制证书配置；用测试确认空控制配置仍使用系统信任库且不跳过证书校验。 |
| I029 | 监控上报的主通道必须是控制连接上的数据流：与控制流同一连接、彼此独立的流，每条流均通过注册握手校验 JoinToken 并绑定明确 Agent 身份；数据流不得写入 Agent 在线注册表，也不得触发生命周期回调（否则会覆盖控制流会话并产生虚假上下线）。 | 隧道测试覆盖数据流注册的角色与 JoinToken 校验、注册后在线表为空、生命周期回调计数为零、控制流注册语义不变。 |
| I030 | 数据流批次必须以流注册身份为准：载荷声明的 Agent 标识与流身份不一致时必须拒绝该批，且该批不得产生任何写入；单批被拒不得中断数据流。 | 服务端测试覆盖身份一致时入库、身份不一致时拒绝且零写入、拒绝后流仍可继续推送。 |
| I031 | 数据流未就绪或推送失败时，Agent 必须回落到兼容上报通道；两条通道均不可用时丢弃本批，禁止在 Agent 侧排队重放，禁止阻塞采集周期。 | Agent 测试覆盖数据流优先、不可用回落 HTTP、推送失败回落 HTTP、双通道皆不可用时不阻塞且不排队。 |

### 规则（允许 / 禁止）

| 编号 | 规则 | 允许/禁止 | 验收方式 |
|------|------|-----------|----------|
| R001 | Agent 未连接、RPC 超时或权限不足时，Server 必须返回可区分错误，禁止降级为成功空结果。 | 禁止 | 建议用 API 错误语义测试验证。 |
| R002 | 容器运行时破坏性操作必须要求明确目标和权限上下文，禁止跨 Agent 复用上一次操作目标。 | 禁止 | 建议用容器操作集成测试验证。 |
| R003 | 指标采集失败可以保留上一批数据，但必须显式标记为陈旧或降级。 | 允许 | 建议用数据新鲜度测试验证。 |
| R004 | 告警通知必须可追踪到触发指标、目标资源和当前状态。 | 允许 | 建议用告警记录与通知测试验证。 |
| R005 | 缺失 Agent 标识的监控上报必须被拒绝；禁止把数据写入空 Agent、随机 Agent 或上一次 Agent。 | 禁止 | 建议用上报 handler 或存储层测试验证。 |
| R006 | 未实现的控制操作必须返回明确错误；禁止返回成功空结果。 | 禁止 | 建议用 API/RPC 契约测试验证。 |
| R007 | 告警审计写入成功后，各通知通道必须独立尝试；单个邮件或钉钉通道失败不得回滚审计，也不得阻断其他通道。 | 禁止 | 用告警任务测试分别注入邮件失败和钉钉失败，确认审计与另一通道仍成功。 |
| R008 | 钉钉 Webhook 只允许官方 HTTPS host、固定机器人路径、标准 TLS 端口和唯一非空 `access_token` 参数；禁止重定向或访问任意用户提供的主机。 | 禁止 | 用 URL allowlist、重定向策略和 SSRF 回归测试验证。 |
| R009 | 告警阈值更新只能修改与请求 `id` 和规范类型同时匹配记录的数值字段；类型不可变，目标不存在时禁止返回成功。 | 禁止 | 用 Repository 测试覆盖零值、未变化、类型不匹配和目标不存在。 |
| R010 | 告警消息标题只允许裁剪后 1–128 字符的单行文本；禁止保存空白、CR/LF 或把标题解释为 HTML/模板。 | 禁止 | 用 schema/service 测试覆盖空白、换行、超长和合法 Unicode 标题。 |
| R011 | 资源持续异常首次满足条件时立即通知；未恢复时每 10 分钟最多重复一次。恢复通知不受旧去重窗口阻塞。 | 允许 | 用缓存过期、持续告警与恢复后重新触发测试验证。 |
| R012 | 容器状态变化只允许由最近 2 分钟内写入的最新状态触发；陈旧历史记录或缺失新批次不得产生变化通知。 | 禁止 | 用预置状态缓存与陈旧容器记录回归测试验证。 |
| R013 | 兼容上报接口（HTTP）必须标记为弃用并保留可用，不得在过渡期内移除或改变其鉴权与限流行为；主通道切换不得降低批次原子性与身份绑定强度。 | 允许（保留）/ 禁止（静默移除） | 契约检查断言弃用标记存在、旧 Agent 仍可上报、隧道批次同样按批次原子写入。 |

## 对外可观测行为

| 场景 | 输入 | 可观测结果 |
|------|------|------------|
| 查看监控面板 | 用户选择节点、容器或主机视图 | 返回目标 Agent 的最新可用指标，陈旧数据带降级标识。 |
| 执行容器操作 | 用户提交容器或镜像操作 | 只影响目标节点上的目标资源，并返回成功、失败或权限错误。 |
| 告警触发 | 指标在完整连续窗口内始终严格超过阈值 | 立即写入可追踪审计并尝试邮件/钉钉通知；持续未恢复时每 10 分钟最多重复一次。 |
| 告警恢复 | 已触发资源获得完整正常窗口 | 写入一次恢复审计并通知，清除活动告警与去重状态。 |
| 告警数据未知 | 样本缺失、陈旧、窗口不完整或间断 | 保持既有状态，不触发也不恢复。 |
| 配置钉钉告警 | 管理员提交启用状态、官方 Webhook、可选签名密钥和提醒范围 | 保存单例配置；后续查询只返回凭据掩码与配置状态，可独立发送测试消息。 |
| Agent 不可达 | 请求目标 Agent 时连接失败或超时 | 用户看到明确不可达错误，系统不伪造成功响应。 |

## 输入 / 输出约束

### 输入合法性

- 合法输入：目标节点标识、资源标识、指标查询条件、容器运行时操作参数、告警阈值、官方钉钉机器人 Webhook、可选签名密钥和用户权限上下文。
- 非法输入：缺失目标节点的破坏性操作、无法验证权限的请求、无法映射到目标资源的操作参数、非官方或可被用于 SSRF 的钉钉 Webhook。
- 处理语义：非法输入必须被拒绝并返回可定位错误；可恢复失败必须保留重试路径。

### 输出约束

- 每条关键不变量或规则必须有稳定编号和验收方式。
- 输出内容必须能被需求、实现计划或测试证据引用。
- 输出不得降低已有 Domain Spec 的约束强度。

## 状态模型

| 状态 | 含义 |
|------|------|
| `agent-disconnected` | Agent 不可达，Server 不能获取实时数据或执行控制操作。 |
| `agent-connected` | Agent 可达，可以接受查询或控制请求。 |
| `collecting` | Agent 正在采集主机、容器或系统指标。 |
| `degraded` | 最近一次采集或操作失败，系统只能展示陈旧数据或部分能力。 |
| `alarm-firing` | 指标满足告警触发条件且尚未恢复。 |
| `alarm-resolved` | 告警恢复条件已满足。 |
| `alarm-unknown` | 当前数据不足以证明持续越界或恢复，既有活动状态保持不变。 |

### 状态迁移

| 起始状态 | 事件 | 目标状态 | 允许/禁止 |
|----------|------|----------|-----------|
| `agent-disconnected` | Agent 握手或健康检查成功 | `agent-connected` | 允许 |
| `agent-connected` | 采集任务开始 | `collecting` | 允许 |
| `collecting` | 采集失败或数据过期 | `degraded` | 允许 |
| `degraded` | 新采集批次成功 | `agent-connected` | 允许 |
| `alarm-firing` | 恢复条件满足 | `alarm-resolved` | 允许 |
| `alarm-firing` | 数据缺失、陈旧或间断 | `alarm-unknown（保持活动状态）` | 允许 |
| `alarm-unknown` | 获得完整持续越界窗口 | `alarm-firing` | 允许 |
| `agent-disconnected` | 执行容器运行时破坏性操作 | `N/A（请求被拒绝）` | 禁止 |

## 错误条件与失败语义

| 错误条件 | 可观测表现 | 是否可恢复 | 是否幂等 |
|----------|------------|------------|----------|
| Agent 不可达 | API/RPC 返回目标不可达或超时 | 是，Agent 恢复后重试 | 是 |
| 指标过期 | 页面显示降级或陈旧状态 | 是，下一次采集成功后恢复 | 是 |
| 容器运行时操作失败 | 用户看到具体失败原因，目标资源状态不被伪造 | 视操作而定 | 视操作而定 |
| 告警通知失败 | 告警状态仍保留，通知通道记录失败 | 是，通知可重试 | 是 |
| 钉钉配置无效 | API 返回可定位的 400 错误且不保存新凭据 | 是，修正配置后重试 | 是 |
| 告警阈值目标不存在或类型不匹配 | API 返回 not found，已有阈值保持不变 | 是，刷新配置后重试 | 是 |
| 告警消息标题为空、含换行或过长 | API 返回 400，原标题保持不变 | 是，修正标题后重试 | 是 |

## 结果约束（非功能性）

| 维度 | 约束 | 验收方式 |
|------|------|----------|
| 可追踪性 | 约束 ID 必须可被需求、实现计划和测试证据回挂 | 引用检查 |
| 确定性 | 相同输入状态必须产生相同领域判断 | 重复执行同一验收场景 |
| 一致性 | 领域状态、可观测行为和错误语义必须互相匹配 | 评审与回归测试 |
| 安全性 | 不记录密钥、Token 或不可公开配置值 | 文档审计 |
